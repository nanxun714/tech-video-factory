# ide 暗色代码教学风规范

适合：编程语言语法、命令行操作、终端工具教学（Python 基础、Linux 命令、git 等）。
参考原片："话多的小孟" Python if 条件判断。活样板：`src/LinuxBasicsTutorial.tsx`。

## 视觉基因

- 深色 GitHub Dark：背景 `#0d1117`、面板 `#161b22`、边框 `#30363d`、正文 `#e6edf3`、弱化 `#8b949e`
- 强调色薄荷绿 `#3ddba4`：标题、终端提示符 `$`、流程框、正确选项、总结胶囊
- 语法高亮：命令/输出用白+绿，代码关键词橙 `#ff7b72`、字符串黄 `#e3b341`
- 终端窗口：更深的 `#010409` 底 + 提示符 `$ `（绿）
- 标注字体微软雅黑，代码一律等宽字体
- 标题结构：顶部居中 `① 命令名：一句话作用`（薄荷绿 + 圈号），下方灰色小字副标题

## 灵魂效果：打字机

`TypeTokens` 组件：tokens = [{t, c}] 带语法色，按 start 帧起以 ~0.9 字/帧逐字显示，
正在输入的行尾跟光标 `▌`（打完后闪烁）。多行按先后 start 帧排队，未开始的行显示为空提示符。

终端行结构：`<TLine><TypeTokens tokens={[{t:"$ ", c:TEAL}, {t:"pwd", c:TXT}]} start={帧} /></TLine>`，
输出行用 `OutLine`（绿色）。**TypeTokens 根元素必须是 span**（div 会把提示符和命令挤成两行）。

## 组件库（LinuxBasicsTutorial.tsx 内已有，直接复制改）

CodeWindow（带红黄绿点的编辑器窗口）、TerminalWindow（终端窗口）、TLine/OutLine、
Callout（红/黄警示卡：⚠ 标题 + 说明行）、Pop、SectionTitle、SummaryPill、Subtitle（浅色文字）。

## 成熟场景模式（按参考片结构）

1. 标题页：大标题（强调色）+ 副标题 + 底部落款，静态完整呈现
2. 命令讲解页 ×N：终端窗口逐字敲命令 → 绿色输出 → 下方荧光黄知识卡（命令全称/作用）
3. 易错提醒页：红色卡（✗/✓ 对比）+ 黄色卡并列，底部总结胶囊
4. 总结页：2~4 张命令卡片横排（命令名+一句话作用）+ 总结胶囊
5. 练习题页：问题 + 小代码窗口 + A/B/C 选项卡
6. 答案页：正确项薄荷绿高亮 + ✅ + 底部结论胶囊
7. 收尾卡："学会了就点个赞！" + 下期预告 + 👍⭐✏️

## 节奏建议

- 每屏打字量 = 该屏旁白讲到的内容；打字速度 ~0.9 字/帧（54 字/秒），讲完命令刚好打完
- 命令敲完 → 停 20~30 帧 → 绿色输出弹出（模拟回车执行）
- 一屏最多 5 行终端历史，再多就拆场景

## 补充模式（第二轮返工沉淀）

- **终端窗口占满画面**：1920 宽下 w=1500（x=210），单命令页字号 34，多行历史页字号 30
- **终端历史"长出来"**：items 数组（{t, el}）按时间穿插命令行和输出行，`filter(frame >= t)` 渲染——未敲的命令不显示空提示符
- **单光标**：TypeTokens 加 `active` 属性；某行的 active = `frame < 下一行start`；最后一行 active 恒真
- **练习题互动倒计时**：出题+选项弹出后，空白区放 3-2-1 圆圈倒计时（每数字 20 帧，teal 圆圈+大数字），倒数完切答案场景
- **答案页保留全部选项**：正确项薄荷绿高亮 + ✅，错误项 opacity 0.3 置灰，观众可对照
- **命令历史里嵌 pwd 验证**：cd 之后接一行 pwd 看位置，教学更完整
