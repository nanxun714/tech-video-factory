# card 卡片动画风规范

适合：抽象概念、数字推演类主题（掩码/哈希/进制/加密）。活样板：`src/SubnetMaskExplainer.tsx` + `src/subnetMaskExplainerData.ts`。

## 视觉基因

- 背景 `#fafaf8` 暖白，标题黑 `#1f2937` 加荧光黄涂抹条（圆角矩形垫底，旋转 -1°）
- 圆角芯片卡片：浅色底 + 同色系细边框 + 16px 圆角，等宽字体写数字
- 四色语义体系（全片一致）：蓝=主对象/IP、绿=成功/正确、橙=网关/主机/警告、紫=掩码/辅助概念
- 标注字体楷体（HAND_FONT），数字一律等宽字体（MONO）

## 布局模式

- 标题：页顶居中，单行 ≤10 字
- 一屏一个主视觉：卡片流程（3 节点横排）、对比双栏、运算行（等号对齐）
- 推演类镜头：元素按讲解顺序 spring 逐个弹出（`Pop` 组件，delay 递增 8~20 帧）
- 运算/对照行：用固定宽度列对齐（如 `width: 380, textAlign: right`），禁止让浏览器自动排版对齐

## 成熟场景模式（直接套）

1. 钩子页：主体卡片 + 红色 ✕ "还差一步"式冲突标签
2. 数字展开页：色块位组逐个点亮 → 分组标签 → 十进制结果落下 → 概念名胶囊
3. 结构拆分页：整体条 → 分成两色两段 + 各段语义标签
4. 判断分流页：两个目标卡片 + 绿色直达箭头 / 橙色绕行箭头（经过中间节点）
5. 边界悬念页：分隔符位置放 "？" 圆点 + 扫描线横移
6. 等价换算页：左卡片 = 右胶囊，配一句结论
7. 运算总结页：等宽字体多行运算 + 每行右侧结论徽章（✓/✕）+ 底部总结胶囊
