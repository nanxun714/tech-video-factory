- **字幕：黄色加粗黑描边**（`#ffd93d` + 8 向 textShadow），逐句显示——贴近原版；此规则仅 sketch 风生效，深蓝灰风仍用深色字幕
- **动画 > 原版**：大白是整页预绘静态图，我们要跟随配音逐元素描画（Draw pathLength=1 dashoffset 滑入 / WCol 缩放淡入），这是相对他的加分项
- 页内纯函数原语：所有组件收 `f`（内容帧）而非内部 useCurrentFrame（页面有 off 偏移），箭头/描画 delay 全部用页内帧
- **切页节奏**：页边界 = 配音句窗口（timeline.json 的句子起止）；一个概念独占一页，单页内容 200~500 帧（7~16s），总览/目录页允许短到 ~5s
- **结尾拆两页**（《虚拟内存》v1 教训：三词卡+面试贴纸+CTA+下期预告+落款塞一页，用户打回"塞住了"）——倒数第 2 页总结、最后一页 CTA，两页都大量留白
- 封面静态元素 delay 传 **-99**（v1 曾传 -1 导致 0:00 只有 8% 笔画近似黑屏，抽帧才抓到）

## 揭示纪律（2026-09-12 借鉴 srt-whiteboard 遮罩不变量沉淀，Draw 逐笔元素适用）

- **遮罩不变量：后画的元素绝不提前露线。** 每个元素的可见范围 = 自身区域 − 所有比自己晚出场的元素区域。落地：①布局期就让晚出元素与早出元素**区域错开**（最省事）；②确实重叠时，早出元素的 Draw 路径裁剪到自身区域内（svg clipPath 或 pathLength 提前收笔），不许线条"借道"晚出元素的地盘
- **ink:color = 2:1 笔迹时序**：一个元素先线稿描画、再水彩填色，填色时长 ≈ 描画的 1/2，且填色在描画完成后才开始——不要线稿和色块同时淡入，那样没有"手在画"的过程感
- **一支笔原则（区域串行）**：同页元素依次作画，下一个元素从上一个描画结束 + 8~15 帧呼吸后开始；视觉上是"一支笔在页面上连续画"，不是各元素同时冒出来
- **凝视收尾**：整页画完后至少留 30 帧（1s）完整画面停留，再进叠化——结尾元素 delay 晚了等于白画

## 视觉基因

- 纯白背景 `#ffffff`，墨线 `#262626`
- 手绘框：`sketchRectPath(x,y,w,h,seed)` 用正弦抖动生成歪扭路径，配合 `SketchBox`（注意它自带 svg 包裹）
- 荧光笔黄 `#ffe066`：垫在场景标题下（`Marker` 圆角条，旋转 -1°）
- 粉彩填充：绿 `#dff0dc`、蓝 `#dbeafe`、红 `#fde3e3`、黄 `#ffe066`，深色描边用同族深色
- 标注字体楷体（HAND_FONT），标题微软雅黑 900（幼圆合成粗体在个别字形上会渲染成空心，勿用于场景标题）
- 手绘箭头：`SketchArrow`（描画动画 draw-on + 箭头头），`flipX` 用于反向

## 布局模式

1. 钩子页：左 中(黄圆"?"，随 frame 呼吸缩放) 右 三点连线
2. 对比页：左对象 → 中间被 ✕ 划掉的主体 → 右对象，两支手绘箭头
3. 流程页：节点卡片 + SketchArrow 串联；节点数 >4 时编号圆徽章
4. 步骤详解页：`步骤N 标题` + 右上角"纯文本阶段"式角注 + 2~3 行「原文 → 结果」对照
5. 全流程总结页：5 节点横向流水线 + 彩色小箭头 + 底部荧光笔结论条
6. 收尾卡：`下期见！`大字 + 两条引导（有疑问？评论区留言 / 想了解的技术？）+ 👋，必须有配音

## 动画语言

- 元素 Pop 弹出（场景 1 除外——封面帧必须完整）
- 箭头 draw-on（delay 按讲解顺序递增 15~20 帧）
- 中心图标可持续动画（齿轮 `rotate(frame*0.4)`、问号呼吸）
- 转场**硬切**，无淡入淡出
