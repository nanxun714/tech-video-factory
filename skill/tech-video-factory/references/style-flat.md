# 扁平可爱插画科普风（flat）

适合：网络/生活化技术科普（内网穿透、VPN、DNS、组网）、A vs B 对比类题材。
活样板：
- `src/TcpVsUdpFlat.tsx`（《TCP vs UDP》2026-09-12 用户点名"做的非常好"，要求"以后按这个来做"——**竞争型 A vs B 九页结构，最新最全，对比类默认照这个做**）
- `src/PortMapVsTunnel.tsx`（《端口映射 vs 内网穿透》决策型六页，2026-09 用户验收）

参考对象："AI研究员-Wen" 系列第 17 集。

## 视觉 DNA（区别于手绘风：无描边线稿，色块即图形）

- 底：白→浅灰渐变 `linear-gradient(180deg,#fff,#f3f6f9)` + BgDots 圆点网格
- **语义双色按题型分两种**：
  - 决策型（两方案要二选一，如端口映射 vs 内网穿透）：A=蓝 #4a86d8、B=绿 #45a56a
  - 竞争型（各有优势看场景，如 TCP vs UDP）：A=蓝 #4a86d8（稳/可靠）、B=橙 #f0912d（快/能量）——橙色在竞争型里承担整个 B 方案，不再是纯点缀
  - 红 #e05656 只给问题/丢失/警告；黄 #f7c948 强调（VS 徽章描边、总结横幅）
- 卡片：白底圆角 26 + `3px solid #e0e6ec` + 顶部撞色标签胶囊（压在卡片上沿）
- 图标全部扁平 SVG（无手绘抖动）：地球/路由器/服务器/云服务器/房子wifi/锁/人物笔记本/前台/问号/路牌/靶心/天平/链条（PortMapVsTunnel）；24x24 material 路径缩放库 Ico：听筒 D_HANDSET/喇叭 D_MEGA/盾牌 D_SHIELD/闪电 D_BOLT/文件 D_FILE/钥匙 D_KEY/直播 D_LIVE/手柄 D_PAD（TcpVsUdpFlat 组件头部，新主题直接抄）
- 标题：微软雅黑 900 撞色（勿用手绘行楷）；黄波浪线垫底 + 星星 Sparkle
- 字幕：白字 46px 黑色半透明圆角底条（此风格不用黄字）

## 结构公式

### 竞争型 A vs B（TcpVsUdpFlat，53s 九页——"一页一件事"铁律的直接展开，别怕页多）

1. 钩子提问：大标题即问题 + 场景图（手机/用户 ↔ 远端服务器 + 循环数据包）+ 虚线疑问胶囊
2. 双主角登场：大标题"TCP 和 UDP" + 左右两张介绍卡（图标+更追求XX大字）+ 中央 VS 徽章——**这一页只保留这三样**，比喻/机制全部往后放（首帧塞满是被打回过的）
3. A 的生活比喻（打电话：两个小人+对话气泡"听到了吗？""听到了！"+绿色确认）
4. B 的生活比喻（大喇叭喊话：喇叭+声波弧+听众+"?"）
5. A 的机制演示（编号签收：发送方/接收方两卡 + 五颗编号包连发 + 3 号半路坠落 + 「3?」气泡 + 重发 + 送达✓槽位逐个亮起）
6. B 的机制反差（五包连发 + 送达槽 ✓✓**✗**✓✓ 3 号空缺 + "不等/不确认/不重传"三连胶囊 + 底部撞色奖励条"换来低延迟"）
7. 场景双卡：左右各一张"走 TCP/走 UDP"卡，卡内 3 行场景条（图标+名称+一句话理由），按口播顺序逐行弹入
8. 一句话总结：两张结论卡 + 黄色微倾斜横幅金句（"不是谁更好 而是看场景需要什么"）
9. 下期预告 + 关注 CTA：预告卡 + 小人 + 撞色关注胶囊 + 落款

页与页边界 = 每句配音的起始帧（组件里 `SENT` 数组），一句一页或明确分页，绝不把两件事挤一页。

### 决策型（PortMapVsTunnel，60s 六页）

1. 封面总览：大标题 + 左右双卡（图标流+虚线标签+说明条）+ 中央大问号"如何选择?" + 底部三卡路线图（原理/前提/怎么选）——开头预告结构是留存技巧
2. 原理页：中心设备 + 两侧卡片 + 飞行数据包箭头 + 绑定关系高亮 + 生活化类比条
3. 前提/痛点页：中心图形打红叉 + 三张编号问题卡
4. 对方方案页：场景隐喻插画 + 红叉直达 + 绿色主动连接
5. 区别+怎么选：两张金句卡 + 决策树
6. CTA：两句金句总结 + 决策口诀 + 点赞 + 下期实操预告

## 动画与词级锚点（2026-09-12 定稿，TcpVsUdpFlat 是标准实现）

- **词级锚点驱动一切**：Step 2 用 `boundary="WordBoundary"` 拿到逐词时间轴后，页内每个元素的 `delay` = 对应关键词的朗读帧（相对句首）。"可靠"说出口的那帧弹"可靠"大字、"3？"一问完气泡出现、坠落包对齐"发现第三个没到"——口播和画面逐词同步，这是本风格"活"的关键
- 卡片/图标 PopAt 弹入（页内按配音顺序 delay 递增）；页面边界对齐句子起始帧，避免关键词刚出现就翻页
- FlatArrow 描画 + 飞行数据包；**LoopPacket** 循环包用于长停留页（请求蓝/响应绿），不能只剩静态箭头
- **FlyPacket 编号数据包**（TcpVsUdpFlat 内）：一次性飞行 + 可选 `fall` 参数（半路坠落旋转下坠）——协议丢包演示的标准件
- **送达槽位数组**：接收方卡内侧一列 ✓/✗ 槽，按每颗包的到达帧逐个弹入；丢掉的包留空缺或红叉。TCP 页全 ✓、UDP 页 ✓✓✗✓✓，一张图讲清"可靠 vs 不保证"
- 底部奖励条（PopAt + 撞色圆角条 + Sparkle）做金句落点；黄横幅 `rot={-1.2}` 微倾斜做总结金句
- **动作音效**：whoosh 每颗包起飞（0.1~0.13）、error 包坠落（0.3）、ding 确认/奖励（0.32~0.34）、pop 气泡/CTA（0.28~0.34）、翻页 transfer（0.14）、bed 0.065——统一挂主组件音效层，全部从词级锚点数组推导，改配音只改一处
- 页间 10 帧叠化（PageTurn），开场页第 0 帧完整静态（delay 传 -99）
- FlatCard 的 children 用**卡片相对坐标**；页内散排元素用页面坐标——两种坐标系混用是本风格最大的坑，禁止混排
- **字幕安全区**：底部字幕条固定 `bottom:30`，主视觉在 `y=930` 前结束

## 纵深分层（2026-09-12 借鉴 paper-cutout 四层模型沉淀，TcpVsUdpFlat 之后的片子逐步套用）

本风格目前是纯 2D 平铺 + PopAt 依次弹入，缺"呼吸感"。借鉴纸片分层方法论，每页按四层组织，**立体感来自前后遮挡，不是镜头移动**：

| 层 | 内容 | 动画节奏 | flat 风落地做法 |
|---|---|---|---|
| 背景 0 | 底色渐变/BgDots/远景色块 | 最慢，只轻微漂移（1~3%） | BgDots 加极慢 translate，别静止 |
| 后排 1-2 | 远处次要元素（对端服务器/城市剪影） | 幅度小，透明度略降 0.85 | 淡色小图标，最后弹入 |
| 主体 3-4 | 本页主角卡片 | 尺寸最大、入场最有力量 | 现有 FlatCard 保持，第一个弹 |
| 前景 5-6 | 近处装饰（Sparkle/纸屑/胶带） | 稍快，**故意压住主体边缘** | Sparkle 从"躲开卡片"改为可轻搭卡片一角 |

- **主次差距硬指标：主角宽度 ≈ 后排角色的 4 倍**；不到 2 倍画面就"平均、没重点"
- **错峰入场三档**：主体先出 → 配角 delay +12~18 帧 → 后排 +26~36 帧，绝不同时弹
- **排版前三问**（先定镜头再摆素材，顺序反了必返工）：谁最大？配角在哪（不许挡主角的脸/道具）？地平线在哪（脚底落在同一合理地面）？

## 踩坑清单（每条都真实付出过返工代价）

1. **flatKit.tsx 的 Pill/Sticker 类型声明 `delay` 但解构 `d`**——调用必须传 `d=` 才生效（tsc 全项目报错属历史遗留，运行正常）。新组件别 import 这些，直接把 TcpVsUdpFlat 头部那份本地 PopAt/FlatCard/Pill/FlatArrow 拷走（Pill 带 border 参数，更全）
2. **flatKit 的 MarkOk/MarkBad 不收 f/d 参数**——要入场动画必须 `<PopAt f={f} delay={n}><MarkOk x={30} y={30}/></PopAt>` 包裹，直接传 f 是 TS 报错
3. **卡内大字（84px 级）与下方小字间距 ≥22px**（TcpVsUdpFlat：大字 top 302、小字 top 424）——296/400 的布局实测叠字，被打回过
4. **Sparkle 别压卡片标签胶囊/徽章**——(560,300) 正好压住 TCP 芯片，验收时发现后挪到卡片外侧空白区
5. **行内图标确认不溢出行底**：130px 高的场景行里 ServerIcon 只能用 s≈0.98，s=1.15 会伸出圆角行外
6. **页尾压轴元素（奖励条/最后弹入的大字）要给 ≥30 帧停留**：PageTurn 末 10 帧整页渐隐，压轴元素 delay 晚了等于白做——口播快（男声+18%）时尤其要卡着词级锚点提前 3~5 帧给 delay
7. **大字弹入用 opacity+scale 同步动画**（`scale(0.7+0.3*ease(p))`），瞬跳没有"砸出来"的感觉
8. 网络链路必须同时表达请求与响应；红色虚线只表示"不通/丢失"，不挡正常路径
9. 渲染前对比 mp4 与 tsx 的 mtime，确认渲染用的是当前代码（会话中断续跑后文件可能已变）；抽帧 QC 用 cv2，别用 Remotion 自带 ffmpeg

## §视觉样板对齐清单（2026-09-14 手机画面感返工沉淀——用户点名的样板必须对齐）

用户已亲自改过/点名认可的具象样板，后续任何片子用到同类元素时**照抄规格，不许退化成占位图**：

- **手机** = `TcpVsUdpFlat.tsx` PageHook 那台（2026-09-13 用户逐项验收）：深色一体化机身 #3f4d5e + 电源/音量侧键 + 挖孔摄像头 + 状态栏（12:30/信号/电量）+ **屏幕里是完整的具体 App 界面**（渐变底短视频页：白板讲课卡+小人+右侧点赞/评论/转发栏+@全栈小秋+音乐条+播放进度条+缓冲马赛克+转圈+小红心循环上飘）。**禁止画成白屏+灰色占位图标/占位线框**——judge 查不出"占位图"（它只判技术正确性），但用户一眼就能看出"没有画面感"。
- 剧情需要变体（卡住/打不开/加载中）：保留全部机身+界面结构，只改状态层（进度条冻住/大转圈+文字/马赛克），如 `PhoneLagFlat` 封面与 `WifiFullBars` 封面。
- 新元素类型（电脑/路由器/服务器等）没有已验收样板时，按同一标准自查：屏幕/面板里有没有具体内容？还是只有色块和线条？
